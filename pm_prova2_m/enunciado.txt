Cenário
Uma empresa de aluguel de automóveis deseja informatizar o sistema de gerenciamento de
veículos e contratos de aluguel.
A empresa trabalha com diferentes tipos de veículos. Cada veículo cadastrado representa
um automóvel específico disponível para aluguel, como:
• Carro: possui quantidade de portas, pode receber avaliação, não precisa de inspeção.
• Moto: possui cilindrada, não recebe avaliação, pode ser inspecionado.
• Van: possui quantidade máxima de passageiros, pode receber avaliação, pode ser
inspecionado.
Todo veículo possui: placa, modelo, ano de fabricação, valor da diária, quilometragem,
status do veículo
A empresa também oferece diferentes tipos de aluguel:
• Básico: permite até 100 km por dia, não possui seguro incluso.
• Premium: possui quilometragem ilimitada, possui seguro incluso.

1

• Executivo: possui quilometragem ilimitada, oferece motorista particular, pode rece-
ber avaliação.

Cada aluguel pode possuir vários veículos associados.
O sistema deve permitir o gerenciamento dos veículos e alugueis disponíveis, além de
funcionalidades específicas relacionadas à avaliação e inspeção dos veículos.
Você receberá prontas as seguintes classes:
• Veiculo
• Aluguel
• enum’s necessários
Seu trabalho será implementar:
• as subclasses concretas conforme enunciado
• as interfaces
• as funcionalidades solicitadas
Interfaces necessárias:
• Interface Avaliavel: deve possuir o método void avaliar(int nota);
• Interface Inspecionavel: deve possuir o método void realizarInspecao( );
Funcionalidades do Sistema
1. Associar veículos a um aluguel
2. Exibir todos os veículos cadastrados
3. Exibir todos os alugueis cadastrados
4. Exibir apenas veículos disponíveis
5. Avaliar objetos que implementam a interface Avaliavel
6. Realizar inspeção em veículos que implementam a interface Inspecionavel
7. Remover veículos em manutenção do sistema
O usuário deve acessar essas funcionalidades através de um menu.
Faça um método na classe main para criar 3 veículos 2 alugueis assim que o programa for
executado.
